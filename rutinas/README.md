# Rutinas
Un archivo por tarea recurrente con el prompt completo. Corren solas en la nube como
Routines de Claude Code (cada disparo abre una sesión nueva) y avisan al celular al terminar.

| Rutina | Archivo | Cuándo (Mexicali) | Conectores |
|---|---|---|---|
| INDIVI seguimiento | `indivi-seguimiento-semanal.md` | Lunes 7:45 | Drive, Gmail, Calendar |
| Meta Ads revisión | `meta-ads-revision-semanal.md` | Lunes 8:15 | Meta |
| Pipeline ATENEA IA | `pipeline-atenea-semanal.md` | Lunes 8:45 | Gmail, Calendar, Drive |

- Para cambiar una rutina: edita el archivo y pide a Claude "actualiza la rutina X".
- Las rutinas solo leen y recomiendan; los cambios al repo quedan en ramas `claude/...`.
- Administrarlas: claude.ai/code → Routines.
